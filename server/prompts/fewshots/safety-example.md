# 安全预案范例（摘自风车课，科学手工课）

一、人员分工
主讲老师：统筹全场，处理突发安全事故
助教：分发材料，巡回提醒危险操作
带组老师：看管本组工具零件，隐患及时上报

二、课前准备
打磨木件毛刺，检查电线无破损，仅使用圆头安全剪刀
备好碘伏、创可贴等急救用品
清理场地杂物，划分操作、垃圾专用区域
开课集中宣讲安全规则

三、课堂安全管控
1. 小零件禁止入口
2. 木件轻拿，不戳人
3. 电线不沾水，不拉扯打闹
4. 剪刀不对人、不挥舞；纸屑统一收纳
5. 全场秩序：取材料、上台有序排队，禁止追逐推搡

四、突发应急处理
1. 误食零件：立即观察呼吸，呛噎窒息马上送医并通知家长
2. 划伤擦伤：碘伏消毒贴创可贴；伤口严重及时送诊
3. 摔倒磕碰：轻微磕碰就地休息；扭伤、撞击头部立刻就医
4. 争抢工具：及时制止，重新强调课堂纪律

五、课后收尾
1. 逐组清点回收全部零件工具，统一收纳
2. 清理木屑、纸屑，保持场地干燥整洁
3. 提醒学生居家不私自拆装电线、手工器材
