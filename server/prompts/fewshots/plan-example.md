# 教案范例（摘自动力车大作战，科学课）

教学目标：
- 知识：了解橡皮筋弹力可以转化为小车前进的动力，知晓简单动力传动原理。
- 能力：掌握手工动力车的组装、制作方法，能独立完成小车制作与调试。
- 情感：培养动手能力、观察思考能力，感受科学与手工结合的乐趣，树立乐于探索的意识。

教学重点：掌握简易动力车的制作步骤，学会利用橡皮筋驱动小车前进。

教学难点：合理固定橡皮筋、调整松紧度，解决小车跑偏、无法前进等问题。

学习者特征分析：授课对象为3-5年级小学生，好奇心强、喜欢动手实践，具备基础手工操作能力；对趣味科学现象兴趣浓厚，但动手精细度不足，使用尖锐工具、粘贴固定时容易出错，空间感知和问题调试能力较弱，需要教师分步引导、实时纠错。

教材内容分析：本课属于科学+手工综合实践内容，依托生活中常见废旧材料制作动力小车，将抽象的弹力原理具象化。内容难度适中，操作流程简单，贴合该年龄段学生认知水平，既能锻炼手部动作，又能渗透基础物理知识，做到玩中学、做中学。
