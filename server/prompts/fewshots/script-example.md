# 逐字稿范例（摘自风车课，一页半）

*【ppt第3页】*

同学们，yuyu最近在森林探险时给我们发来了一段视频，我们先来看一看。（播放视频）

诶，小朋友们，yuyu现在一个人在黑漆漆的大森林里，周围全是树，手电筒里一丁点儿电都没有了，它非常着急。森林里没有插座可以充电，没有小卖部可以买电池。那怎么办啊？难道就让yuyu一直被困在黑暗里吗？

别慌！其实，在我们美丽的家乡——海南，就有一种神奇的"魔法巨人"。它们不需要插座，也不需要买电池，只要站在海边吹吹风，就能凭空变出源源不断、用都用不完的电！

大家猜猜，这些"魔法巨人"是谁？（提示标题，台下互动：大风车/风力发电机！）

*【ppt第4页】*

对啦！就是风车！今天老师就带大家去我们海南有名的"风车海岸"看一看，看看这些巨人有多威风！（播放视频）

视频看完了，这些现代的大风车是不是超级酷？海风一吹，它们的大翅膀就飞快地转动起来，把吹过来的海风，"啪"的一下变成源源不断的神奇电力。这些电顺着长长的电线，传到我们每一个小朋友的家里，让我们能看电视、吹空调、给手机充电，让整个海岛都亮堂堂的！

*【ppt第5页】*

小朋友们，这些白色大风车长得那么高、那么大，那它的身体到底是由哪几个部分组成的呢？让我们一起来拆解一下这位发电大英雄的身体！（指向大屏幕）

魔法巨人其实只有三个最神气的身体部位：第一，是它头上这三个大大的、像风扇一样的"大翅膀"（扇叶），专门用来捕捉海风。第二，是它脚底下这根顶天立地的"大高个柱子"（支架），把它举得高高的去吹风。还有第三个，也是最神秘、最重要的部位——就是翅膀后面背着的机舱！
