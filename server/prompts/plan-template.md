# 教案骨架模板与 JSON Schema

> 与前端 src/schema.js 保持一致（两处互相指向，改结构要同步改）。

输出 JSON 对象，字段如下：

```json
{
  "教学时间": "",
  "执教者": "",
  "课目": "",
  "课时安排": "2课时（80分钟）",
  "教学目标": { "知识": "", "能力": "", "情感": "" },
  "教学重点": "",
  "教学难点": "",
  "教学准备": { "教师": "", "学生": "" },
  "学习者特征分析": "",
  "教材内容分析": "",
  "教学过程": [
    { "分钟": "0′-5′", "环节": "情境导入", "ppt": "Slide 1",
      "教师活动": "", "学生活动": "", "设计意图": "" }
  ],
  "板书设计": "",
  "安全预案": { "人员分工": "", "课前准备": "", "课堂管控": "", "突发应急": "", "课后收尾": "" },
  "教学反思": ""
}
```

## 各板块写作要求

| 板块 | 要求 |
|---|---|
| 教学目标 | 知识/能力/情感三维；动词开头（知晓、掌握、培养）；面向混龄分写低年级底线目标与高年级提升目标 |
| 教学重点 | 一节课最核心的 1-2 条 |
| 教学难点 | 学生最难理解的 1-2 条 + 为什么难 + 突破策略 |
| 教学准备 | 教师教具、学生材料分开写；注明数量与分组方式（乡村物资优先废旧材料） |
| 学习者特征分析 | 年级范围、混龄情况、认知特点、注意力特点（乡镇儿童活泼好动，动手能力强，注意力持续时间有限） |
| 教材内容分析 | 课程内容与设计思路（本课是自编课外内容，写清知识脉络与为什么这样设计） |
| 教学过程 | 逐环节：分钟区间 + 环节名 + PPT 页 + 教师活动（含主讲话术要点）+ 学生活动 + 设计意图；环节含导入→新知→实践→总结；动手环节前必写安全规则宣讲 |
| 板书设计 | 结构化条目，简洁可抄写 |
| 安全预案 | **五块必填**（支教安全红线）：人员分工（主讲/助教/带队老师职责）、课前准备（材料检查/急救用品/场地清理）、课堂管控（工具规则/秩序管理）、突发应急（误食/划伤/摔倒/争抢的处置流程）、课后收尾（清点回收/清理场地） |
| 教学反思 | 留空，上完课后再填 |
